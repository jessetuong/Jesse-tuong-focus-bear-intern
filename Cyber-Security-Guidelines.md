# Research & Learn
- Common threats in remote work: Phishing emails/messages impersonating colleagues or services,Unsecured home/public Wi-Fi, Weak or reused passwords, Personal devices without proper security (no lock screen, outdated OS)
- Best practices for securing devices/accounts: Strong, unique passwords per account, managed via a password manager, Enable 2FA everywhere it's offered, Keep OS/apps/browsers updated
- Why lock your computer when away: Prevents anyone nearby from accessing accounts, emails, or company/user data left open, Especially important given Focus Bear handles sensitive health/identity data
- Handling suspicious links: Don't click links or open attachments from unexpected/unknown senders, Check the sender's actual email address, not just display name, Hover to preview URLs before clicking
- Passowrd manager: Long (12+ characters), random, unique per site — not a memorable phrase reused everywhere, A password manager generates and stores these so you don't need to remember or reuse them
- Why 2FA matters: Adds a second barrier even if a password is leaked/guessed, Should be enabled on all work accounts, especially email, code repos, and any account with access to user data

# Reflection: 
- Current habits to assess honestly: password reuse, whether 2FA is on.
- Making security a habit: tie it to routine, use tools that make the secure choice the easy choice (password manager autofill, 2FA prompts)
- Password/account steps: set up a password manager, audit and update weak/reused passwords, enable 2FA on all work accounts
- Suspected breach: don't try to fix it quietly — report immediately to your supervisor/security contact, change affected passwords right away, document what happened
