# What makes Focus Bear different from these apps:
- It's the only one of these that combines blocking + routines + break management in one app, rather than doing just one thing well (Freedom/Cold Turkey = blocking only; Tiimo = planning only; Routinery = routine execution only)
- Built directly by a founder with ADHD/autism, which shows in details like low-dopamine blocked-site views and call-aware reminders

# Why a user might choose Focus Bear over competitors:

- If users don't want to use each app for each function (planning, blocking, routine managing), they should use Focus Bear - the only app that covers all three in one place
- Want a blocking app that is flexible (with functions such as strictness levels adjustment) rather than Cold Turkey's all-or-nothing lockout

# One feature other apps have that Focus Bear doesn't:

- Tiimo's AI Co-Planner — this feature allows users to speak a brain dump and it auto-breaks tasks into a real schedule. It is a function that is way more sophisticated than what Focus Bear appears to offer. Focus Bear is stronger on blocking and routines than on flexible day-to-day task breakdown
- Cold Turkey's "Frozen Turkey" nuclear lockout is also a feature that Focus Bear doesn't have - a feature that doesn't allow users to self-override

# One improvement Focus Bear could make

- Add an extreme blocking schedule, same as what Cold Turkey offers - which is the easiest improvement Focus Bear could make in the near future
