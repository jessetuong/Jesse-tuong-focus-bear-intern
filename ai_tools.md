# AI tools usage reflection
- I tried both 3 suggested AI for coding. Personally, the integrated Github Copilot is extremely handy and convenient since it can refine my code directly in VSCode while I was coding. This helps me avoid small syntax errors (in case I forgot sny syntax), which makes quick code refinement extremely easy. On the other hand, while ChatGPT and Claude Code can not refine my code directly on-the-go, they are more powerful and could generate a whole app by themselves.
- Personally, built-in coding AI like Github Copilot is most useful when I'm new to a coding language, which makes me to usually forget syntaxes. In those cases, Github Copilot would help me to correct the syntaxes on-the-go which is super handy. On the other hand, Claude Code and ChatGPT are most useful to build repetitive functions for an application such as login/logout, booking,.. which are tasks that are easy to build but require the developers repeat similar lines of code everytime. By using Claude Code and Copilot for those tasks, developers would definitely save a lot of time, and could spend their time in more advanced features.
