# Research & learn:

- Key Agile roles
1. Developers: build and maintain the product — write code, fix bugs, review PRs, estimate technical effort
2. QA: test features for bugs/edge cases, write test plans, verify fixes before release, protect product quality
3. Product Manager (PM): defines what to build and why — owns priorities, roadmap, and user/business needs
4. Agile Project Manager / Scrum Master: facilitates the process — runs ceremonies, removes blockers, keeps the team on track (not the same as deciding what to build)
5. Other supporting roles: stakeholders (give input/approval on direction), UX/design (shapes usability and interface), customer support (surfaces real user pain points back to the team)
- Collaboration in Kanban vs. Scrum
1. Scrum: roles work in fixed sprint cycles — PM prioritizes the backlog before sprint planning, devs/QA commit to a sprint's worth of work together, Scrum Master runs stand-ups/retros/planning
2. Kanban: more continuous — PM keeps the backlog prioritized in real time, devs pull the next-highest item as capacity frees up, QA tests continuously rather than at sprint boundaries, no fixed sprint ceremonies required
