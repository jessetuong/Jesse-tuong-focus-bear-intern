# Research & Learn
- My key takeaways: Legal bases: consent, contract, legal obligation, legitimate interest. Shared only with named processors (AWS, Stripe, OpenAI, Auth0, etc.). Data kept only as long as needed; users have full GDPR rights
- Confidential data types: health/ medical info, religious inference, financial data, login credentials, identification data.
- Best practices for handling confidential data: collect only what's necessary, encrypt sensitive fields, restrict access to appropriate staffs, inform users before repurposing data, use vetted, compliance processors only.
- Responding to a suspected data breach: Report internally immediately, report to security owner, let formal process handle authority + user notification per GDPR timelines.
# Reflection
- Daily habits: access data only when needed; use approved tools; keep keys/credentials out of plaintext; lock devices when away.
- Storage/sharing/disposal: use encrypted/approved systems, not personal drives; share via secure channels, not email/chat; securely delete when no longer needed.
- Common mistakes: oversharing, weak passwords, unencrypted sharing, over-retention.
