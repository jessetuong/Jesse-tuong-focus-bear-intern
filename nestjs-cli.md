## How does the NestJS CLI streamline development?
- It automates creation of common NestJS components and reduces the amount of boilerplate developers need to write manually.

## What is the purpose of nest generate?
- It generates NestJS application components such as controllers, services, modules, guards, pipes and other files using standard NestJS templates.

## How does the CLI ensure consistency?
- Developers use the same commands and NestJS-provided templates, resulting in consistent naming, decorators, file structures and coding patterns throughout the project.

## What files/templates does it create by default?
- Depending on the component, it creates TypeScript source files and commonly a corresponding .spec.ts test file. For example, a controller generates a .controller.ts and .controller.spec.ts, while a service generates a .service.ts and .service.spec.ts. Modules generally generate the .module.ts file.
