# Research & Learn:
- AI tools typically used for this role: Claue, ChatGPT, Gemini (AI Agents).
- Benefits of usign AI: faster drafting, debugging help, research summarization, reduced repetitive work. Risks of using AI: hallucinated/incorrect info, leaking confidential data into third-party tools, over-reliance eroding your own skills, biased or outdated outputs.
- Info that should never go into AI tools: User personal data, Login credentials, Unreleased company products/plans.
- Fact-checking AI outputs: Cross-check facts/figures against primary or official sources, test code before trusting it (run it, don't just read it), watch for confident-sounding but unverifiable claims.

# Reflection:
- Use AI for: drafting, brainstorming, boilerplate code, summarizing long text, catching typos/bugs
- Tasks I should rely on my own skills; judgment calls, anything involving user privacy/ethics, final decisions, domain expertise checks.
- Avoiding over-reliance: always review output critically, occasionally do a task manually to keep skills sharp, treat AI as a first draft, not a final answer
- Data privacy steps: never paste real user data into AI tools, use anonymized/sample data for testing, stick to company-approved AI tools
