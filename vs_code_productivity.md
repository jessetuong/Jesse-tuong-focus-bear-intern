## My top 10 shortcuts in VSCode:
- Cmd+P — quickly open any file by name
- Cmd+Shift+O — jump to a symbol/function within the current file
- Cmd+T — search for a symbol across the whole project
- Ctrl+G — jump to a specific line number
- Cmd+D — select the next occurrence of the current word (great for multi-editing repeated text)
- Option+Click — add a cursor anywhere you click (multiple cursors!)
- Cmd+Option+Down/Up — add a cursor directly above/below the current line
- Cmd+/ — toggle comment on the current line(s)
- Option+Shift+Down/Up — duplicate the current line down/up
- Cmd+Shift+K — delete the entire current line
## Reflection:
- Personally, Cmd+P is the one that I used the most throughout the time I use VSCode. Simply because it is very handy when working with a large project such as my capstone project where I built a backend of a Service Marketplace App by myself. Specifically, as it is a large app, it has many modules and many files. Thus, having a shortcut key such as Cmd+P is extremely convenient because it helps me to navigate to the files that I want quickly, and help me to save a bunch of time.
- As explained above, Cmd+P and other shortcut keys are extremely handy, they help save a bunch of time, which allows developers to have more time to work on other things, which helps improve the productivity.
